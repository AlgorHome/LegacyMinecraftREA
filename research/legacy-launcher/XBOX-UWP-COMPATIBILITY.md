**Confirmed official contract:** VirtualProtectFromApp supports JIT with codeGeneration and disallows simultaneous write/execute protection. It is incorrect to conclude “UWP cannot JIT.” LoadPackagedLibrary searches the package dependency graph and disallows absolute/parent-traversal paths. Neither contract proves that this desktop JVM/native set works on Xbox.

**Confirmed official scope:** FullTrustProcessLauncher belongs to Windows Desktop Extension SDK and is not an evidenced Xbox escape hatch. Current generic CreateProcessW documentation includes UWP in its requirements; that row alone does not establish Xbox arbitrary desktop process permission. [FullTrustProcessLauncher](https://learn.microsoft.com/en-us/uwp/api/windows.applicationmodel.fulltrustprocesslauncher?view=winrt-26100)

The resource guidance is under previous-versions and dated 2017; its published 1 GB app/5 GB game figures require current package/device verification. No new hardware test occurred. Xbox gameplay feasibility remains **Unknown** for the unvalidated combinations identified here.

## Continuation: measured static scope and actual blockers

NATIVE-DEPENDENCIES expands the native audit to291 PE observations including archive DLLs and delay imports. Specific GLFW source limitations include false extension queries, NULL Win32 window handles, absent hats and ignored mapping updates; investigate consumers instead of extrapolating universal failure. GameInput/controller and suspension/resume source hooks are already present. Exact package capability declarations are recorded without assuming they are granted on Xbox. [E14/E15]

Microsoft's [Xbox UWP limitations](https://learn.microsoft.com/en-us/uwp/extension-sdks/uwp-limitations-on-xbox) additionally limit folder picker scenarios, drag/drop, broad filesystem access, key credentials and roaming settings; this does not imply all PasswordVault APIs fail. Runtime verification requires the actual package/device. Owner-confirmed missing VM/remote-console infrastructure makes every new behavioral test BLOCKED. The complete56-row matrix and XBOX-SERIES-X-TESTS preserve the full scope.
